# Cistercian playground

This is a small web app I've built to get more acquainted with [Cistercian numerals](https://en.wikipedia.org/wiki/Cistercian_numerals).

It offers several modes to get familiar with these cool numerals, described below.

## Diplay

Input any number between 1 and 9999 to see its cistercian numeral counterpart.

## Practice

Practice _'writing'_ cistercian numerals for a given number.

## Guess

Practice _'reading'_ cistercian numeral by guessing which number the given numeral represents.

## Clock

Show off with your friends with a full screen clock that displays time with cistercian numerals!
